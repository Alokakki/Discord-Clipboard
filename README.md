# Discord Clipboard

A lightweight web app that rotates through a list of crypto-themed quotes and lets you copy the current one to your clipboard with one click.

## Features

- Rotating slogan/quote display
- Copy-to-clipboard button
- Adjustable rotation timing
- Next quote button
- Simple, clean single-page design
- Works directly in the browser

## Live Demo

https://alokakki.github.io/Discord-Clipboard/

## Project Structure

- `index.html` – page layout and app structure
- `styles.css` – styling for the UI
- `script.js` – quote rotation, timer logic, and clipboard behavior

## How to Use

1. Open `index.html` in a browser, or use the GitHub Pages demo link.
2. Choose the time interval for quote rotation.
3. Click "Copy" to copy the currently displayed quote.
4. Use "Next" to move to the next quote manually.

## Notes

This project is designed as a simple utility for quick inspiration or sharing short crypto-themed messages.
